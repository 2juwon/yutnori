# 한판 윷놀이

https://2juwon.github.io/yutnori/

가족끼리 한 기기로 돌아가며 던지거나, 컴퓨터와 겨루는 윷놀이예요. 설치 없이 휴대폰 브라우저에서 바로 열려요. 규칙은 나무위키 「윷놀이」 문서를 따랐어요.

## 규칙
- 도 1 · 개 2 · 걸 3 · 윷 4 · 모 5칸, 빽도는 왔던 길로 한 칸 뒤
- 윷·모가 나오거나 상대 말을 잡으면 한 번 더 던짐
- 내 말이 있는 칸에 멈추면 업기, 상대 말이 있는 칸에 멈추면 잡기(업힌 말 모두 처음으로)
- 모·뒷모 모서리, 가운데 방에 **멈추면** 지름길로 꺾음. 지나가기만 하면 곧게 감
- 참먹이를 **지나가야** 남. 도 자리에서 빽도면 참먹이로 가고, 다음엔 무엇이 나와도 남
- 판 위에 말이 없을 때 나온 빽도는 쉬어 감

## 설정
- 2~4편, 편마다 이름과 사람 / 느긋한·보통·고수 컴퓨터
- 한 편 말 2~5개
- 윷 확률: 반반(동전식, 개가 가장 잦음) / 진짜 윷(반원기둥 윷가락, 걸이 가장 잦음)
- 지역 규칙: 빽도, 나온 윷 순서 바꿔 쓰기, 빽도로 잡아도 한 번 더, 참먹이에 멈춰도 남, 낙(5%)

진행 중인 판과 설정은 각자 브라우저에만 저장돼서 새로고침해도 이어서 할 수 있어요.

## 파일
| 파일 | 내용 |
| --- | --- |
| `index.html` | GitHub Pages로 열리는 완성본 (`node build.js`로 만듦) |
| `src/engine.js` | 규칙 엔진 — JSON 상태 + `apply` |
| `src/ai.js` | 컴퓨터 — 남은 칸·잡기·상대가 올 확률로 수 고르기 |
| `src/ui.html` | 화면 (윷판 SVG, 윷가락 애니메이션, 설정) |
| `build.js` | `src/`를 합쳐 `index.html`과 `dist/yut.html`(Claude 아티팩트용) 생성 |
| `test/rules.test.js` | 규칙 시험 55개 |
| `test/sim.js` | 컴퓨터끼리 대국 (`node test/sim.js 400`) |
| `test/browser.py` | Playwright로 브라우저 자동 플레이 |

## 고치는 법
```
# src/ 수정 후
node test/rules.test.js
node build.js
git add -A && git commit -m "..." && git push
```
